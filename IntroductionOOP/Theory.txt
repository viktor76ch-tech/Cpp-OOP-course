Объектно-ориентированное программирование

Введение в ООП
ООП (object-oriented-programming)- это подход, при котором программа строится из объектовю
Объект - это некая сущность, которая существует в пространстве и времени. Объекты могут
существовать в объективной, субъективной или виртуальной реальности. 
ООП позволяет спроецировать из объективной или субъективной реальности в виртуальную.
Обсолютно все объеты обладают некими характеристиками, состояниями и поведениями.
Объекты принято классифицировать. Класс - это множество объектов с одинаковыми набором
характеристик, состояний и поведений. С точки зрения ООП, класс - это синтаксическая 
конструкция, позволяющая описывать объекты. Классы состоят из полей или членов. Поля или
члены класса бывают двух видов - переменные и методы. Классы часто изображают  UML (Unified 
Modelling Language) - диаграммой. 
_______________________
|   Class / Struct    |
|_____________________|
|                     |
|        Data         |_________Переменные члены класса (Member - variables)
|                     |         описывают характеристики объектов, и их состояния
|_____________________|
|                     |
|       Methods       |_________Определяют поведение объектов, и взаимодействие их
|                     |         с другими объектами. Member-function (Функции - члены
|_____________________|         класса).

Метод - это функция в нутри класса. Метод может быть вызван только для какого-то объкта.
Кроме классов, объекты можно также описывать с помощью структур. Структура - это такая же
синтаксическая конструкция, позволяющая описывать объекты.
Создавая структуру или класс мы создаем новый тип данных (пользовательский тип данных)
Пользовательские типы являются более сложными, поскольку могу включать в себя множество
однотипных или разнотипных значений, которые являются характеристиками и состояниями 
объектов.
Структура - это тип данных;
Класс - это тип данных;

Досту к полям объектов.
Для доступа к полям объекта используются операторы:

.  - Оператор прямого доступа (Point operator) - предназначен для доступа к полям объекта
     по имени объекта
-> - Оператор косвенного доступа (Arrow operator) - предназначен для доступа к полям объекта
     по адресу объекта.

-------------------------------------------------------------------------------------

Концепции ООП
ООП базируется на трех основных концепция:
1. Инкапсуляция (Encapsulation);
2. Наследование (Inheritance);
3. Полиморфизм (Polymorphism);

ИНКАПСУЛЯЦИЯ
Инкапсуляция - это сокрытие определенной части класса от внешнего мира.
Инкапсусяция реализуется модификаторами доступа и get/set - методами. В языке С++ имеются
следующие модификаторы доступа:
private:   закрытые поля, доступны только внутри класса
public:    открытые поля, доступны из любого места программы
protected: защищенные поля, доступны только в нутри класс и его дочерних классов

Переменные члены класса в обязательном порядке должны быть в private-секции, переменные 
обязательно должны быть закрыты. Размещение переменных в public-секции - это грубейшее
нарушение инкапсуляции.
В public-секции как правило распологают методы, хотя методы могут быть расположены в 
private-секции, это нарушением не является.
Примечание: Единственное отличие между классом и структурой заключается в том, что у 
структуры все поля открыты, если не указано обратное, а у класса все поля закрыты, если
не указано обратное.

get/set - методы:
get (взять, получить) - эти методы открывают доступ к переменным членам класса на чтение,
т.е. позволяют получить значение переменной в классе.
set (задать, установить) - эти методы открывают доступ к пеменным членам класса на запись,
т.е. позволяют задавать значения закрытых переменных. Кроме того, set-методы обеспечивают
фильтрации данных, т.е. предотвращают попадание некорректных значений в переменные члены
класса.
Обсолютно у каждой переменной в классе должны быть свои get и set методы. Т.е гетеров и 
сетеров будет столько же, сколько и переменных в классе.

get-методы обязательно должны быть константами. Констрантными называется метод, который 
не изменяет объект, для которого вызывается.
Для константного объекта могут быть вызваны только константные объекты.

this - это указательный объект, для которого вызывается метод. Изнутри объекта никогда 
нельзя узнать его имя, но всегда можно узнать его адрес при помощи this.

Особые методы в классе
В любом классе должно быть как минимум три особых метода:
1. Конструктор (Constructor).
2. Диструктор (Destructor).
3. Оператор присваивания(Assignment operator).

Конструктор - это метод, который создает объект, а именно, выделяет память под объект,
              и инициализирует его поля (переменные члены класса);
Диструктор - это метод, который уничтножает объект по истечении его времени жизни. Время
жизни истекает при выходе за пределы области видимости, в которой он объявлен. Это может
быть функция, if, цикл и вообще любые фигурные скобки, поскольку фигурные скобки порождают
области видимости и пространства имен. 
Конструктор и диструктор называются так же как и класс, но перед диструктором ставится ~.
Конструктор и диструктор никогда не возвращают никаких значений и при этом перед ними даже
не пишется void.
Конструктор, как и любая другая функция может принимать параметры, следовательно, как и любую
другую функцию его можно перегрузить, именно поэтому в классе может быть сколько угодно
конструкторов. Диструктор же не принимает никаких параметров и перегрузить его нельзя, именно 
поэтому в классе может быть только один диструктор. Другими словами, объекты могут создаваться
по разному и самыми разными способами, но независимо, каким образом они были созданы, 
удаляются они одинаково.
Конструкторы бывают с параметрами, без параметров, поумолчанию, конструктор копирования,
конструктор переноса.
Конструктор по умолчанию - это конструктор может быть вызван без параметров. Это может быть 
конструктор, не принимающий никаких параметров, или же конструктор, каждый параметр которого
имеет значение по умолчанию. К. по умолчанию всякий раз неявно вызывается когда мы просто создаем
объект и не знаем каким он будет, в таком случае создается объект по умолчанию и каждое
поле такого объекта должно хранить значение по умолчанию. К. по умолчанию может быть неявным.
Если программист не написал ни единого конструктора в классе, то компилятор сам неявно добавит
туда К. по умолчанию, поскольку без конструктора невозможно создать объект. Такой неявный 
К. по умолчанию просто выделяет память под объект и заполняет его поля мусором. Если в классе 
написать хотя бы один конструктор, то неявный конструктор по умолчанию от туда сразу же
удаляется.
К. копирования - это конструктор, который копирует объект, а именно, создаваемый объект делает
точной копией существующий объект. К. копирования всегда принимает константную ссылку на
объект. Объекты могут копироваться явным образом, например: Point D = C; или не явно, при 
передаче объектов функцие по значению.
